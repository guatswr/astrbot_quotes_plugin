# 语录 (Quotes)

一个用于 AstrBot 的 QQ 群聊语录记录插件。群友的金句、搞笑发言、经典语录，一键收藏、随机回顾。

</div>

## 功能

> 以下示例使用默认的 `/` 唤醒前缀；若 AstrBot 配置了其他前缀，请对应替换。

### 上传语录

回复目标消息后发送以下指令：

| 指令 | 说明 |
|------|------|
| `上传` | 将回复的消息记录为语录，归属原发送者 |
| `上传 @某人` | 将当前上传内容归属给指定用户；回复场景下也会覆盖默认归属 |
| `上传 QQ号` | 将当前上传内容归属给指定 QQ 号；回复场景下也会覆盖默认归属 |
| `上传 已绑定标签` | 将当前上传内容归属给该标签绑定的用户，不会创建同名图库 |

- 支持纯文本、图片、图文混合消息
- 支持回复 QQ 合并转发 / 聊天记录消息并收录为聊天记录语录（仅支持“回复后上传”，并可继续用 `@某人` / `QQ号` 覆盖归属）
- 回复消息时默认归属给**被回复消息的发送者**
- 若同时写了 `@某人` 或 `QQ号`，则以指定对象为准，覆盖默认归属
- 若被记录的用户在黑名单中，将拒绝上传
- 上传的图片会进行 SHA-256 精确判重 + dhash 感知哈希近似判重；资源池已有图片会直接复用，不重复落盘
- 同一次语录或聊天记录上传中包含重复图片时会拒绝，避免一条语录重复引用同图
- 同一会话内，若同一归属用户已存在相同内容的语录，也会拒绝重复上传
- 图文混合语录会按原有顺序保存为单条语录，发送时通过图文合并消息发送
- 聊天记录语录会保留顺序与常见媒体，发送时恢复为聊天记录格式
- 聊天记录中的图片、语音、视频、文件会优先保存到本地；无法保存的媒体会降级为占位符，不影响整条语录保存
- 上传成功时仅回复：`我学会啦，来问问我吧！高性能ですから~`

### 随机语录

| 指令 | 说明 |
|------|------|
| `语录` | 随机发送一条语录 |
| `语录 @某人` | 仅随机指定用户的语录 |
| `语录 QQ号` | 仅随机指定 QQ 号的语录 |
| `/语录列表 [页码]` | 按最新优先分页查看当前会话语录，每页 10 条 |
| `/语录排名` | 按当前会话中每位发送者的收录数量排名 |

- 语录包含图片时直接发送原图，无图片则渲染语录卡片
- 当语录同时包含文字和图片时，会按顺序发送图文混合消息链
- 纯文字模式或卡片冷渲染超时时，会以“发送者头像 + `❝ … ❞` 引用排版 + 独立署名”的消息链回退
- 包含图片的语录会在原图文后附上发送者 QQ；如已绑定标签，则优先显示 tag
- 新的静态图片会在入池前压缩为最长边 2560 px、最大约 1.5 MiB 的 JPEG，按 `img_{id}.jpg` 重命名；动态 GIF 保留原始字节、帧与时序，按 `img_{id}.gif` 保存并原样发送
- 当语录为聊天记录语录时，会按聊天记录格式发送合并转发节点消息
- 开启**全局模式**后，随机范围覆盖所有群/私聊；否则仅限当前会话
- 同一聊天会话内严格避免连续返回同一条语录；普通指令、标签触发和戳一戳共享防重复状态，候选池只有一条时除外
- 没有对应语录时会提示记忆库为空，并引导使用 `/上传`
- `/语录列表` 始终按当前会话列出，不受 `global_mode` 影响；例如 `/语录列表 2` 查看第 2 页
- `/语录排名` 也按当前会话统计；如果用户已绑定 tag，排名中优先显示 tag

### 频率限制

- 每个会话内，每位用户在 2 分钟滑动窗口内最多触发 4 次内容发送事件
- 限制同时覆盖 `/语录`、绑定 tag、戳一戳和随机图库，四种入口共享计数
- 第 5 次会 `@` 触发者并显示剩余冷却秒数；在该限制时间内的后续触发保持静默
- 最早的一次记录离开 2 分钟窗口后自动恢复，重启插件也会清空内存中的限流状态

### 随机图库

回复一张或附带多张图片，发送 `/上传 图库关键词`。参数不是 QQ 号且消息中没有 `@`用户时，图片会存入当前会话的同名图库。

```text
/上传 曼彻斯特咖啡         # 回复或附带图片
曼彻斯特咖啡                  # 随机返回该图库的一张图
/图库列表                       # 查看当前会话全部图库
/图库图片删除 曼彻斯特咖啡 # 回复上一张图，只删除该图
/图库删除 曼彻斯特咖啡   # 删除整个关键词图库
```

- 触发时只检查纯文本普通消息；去除首尾空白后，整条消息必须与关键词完全相同，且区分大小写
- 消息包含额外文字、图片、回复、`@` 或其他非纯文本消息段时不会触发
- 选图时会排除该图库最近发送的最多 20 张图；图库不超过 21 张时，会先完整轮换再重复
- 图库按会话隔离，不计入语录列表或语录排名
- `/图库列表 [页码]` 按名称分页显示当前会话图库及图片数量，每页 20 个
- 管理员回复机器人发送的单张图库图片后，发送 `/图库图片删除 关键词`（别名 `/删除图库图片`）只移除该图
- `/图库删除 关键词`（别名 `/删除图库`）删除整个图库；仅群管理员、群主或 Bot 管理员可用，且需在 60 秒内再次发送同一指令确认
- 图库图片和语录图片共用资源池；静态图压缩、动态 GIF 保持原样，重复图片只复用索引而不重复落盘

### 标签绑定

| 指令 | 说明 |
|------|------|
| `/绑定 @某人 tag` | 在当前会话新增 `tag` → QQ 映射 |
| `/绑定列表` | 查看当前会话的全部映射 |
| `/重新绑定 @某人 tag2` | 将该 QQ 的标签改为 `tag2` |
| `/重新绑定 @某人` | 取消该 QQ 的绑定 |

示例：

```text
/绑定 @张三 名言
名言                    # 随机发送张三的一条语录
/重新绑定 @张三 金句    # 将“名言”改为“金句”
/重新绑定 @张三         # 取消绑定
```

- 标签匹配区分大小写；去除首尾空白后，整条消息必须只有标签文本
- 消息包含图片、回复、`@` 或其他非纯文本消息段时不会触发
- 每个会话内一个 QQ 只能绑定一个标签，一个标签也只能对应一个 QQ
- 标签不能与当前会话已有图库同名；上传参数命中已有标签时会归属到绑定用户，不会另建图库
- `/绑定` 不会覆盖已有映射；修改或取消映射必须使用 `/重新绑定`
- 绑定关系始终按会话隔离；`global_mode` 只改变标签触发后的语录查询范围
- 已绑定用户的纯文字语录会使用标签作为图片右下角签名和纯文本署名，包括普通 `/语录` 与标签触发；未绑定用户仍显示昵称或群名片
- 新增或修改绑定后，已有语录会在后台生成独立的标签签名缓存，不覆盖普通语录缓存
- 标签已有映射但对应用户没有语录时，会返回记忆库提示，不会静默

### 删除语录

回复机器人刚发出的随机语录消息后发送 `删除`（或 `删除语录`）。

- 删除时会按**你回复的那条 Bot 语录消息**精确定位对应语录，而不是简单删除“最近一条”

删除权限由 `delete_permission` 配置项控制：

| 权限级别 | 可删除人员 |
|----------|------------|
| `群员` | 所有人 |
| `管理员` | 群管理员 + 群主 + Bot 管理员 |
| `群主` | 群主 + Bot 管理员 |
| `Bot管理员` | 仅 Bot 管理员 |

### 缓存清理

发送 `/语录缓存清理` 可删除当前群聊或私聊会话的全部语录渲染缓存，包括普通昵称卡片、标签签名卡片和临时缓存文件。清理不会删除原始语录、图片或聊天记录资源；后续再次触发对应语录时会自动重新渲染。成功清理后会追加亚托莉风格的完成提示。

### 存储体检

发送 `/语录存储检查` 可只读检查当前会话的语录、图库、图片和媒体资源，报告缺失文件、无效引用、引用计数不一致、孤儿文件以及标签/图库同名冲突。该命令不会修改或删除任何数据。

### 戳一戳触发

对 Bot 发送"戳一戳"（Poke）时，按配置的概率随机发送一条语录。

- 需开启 `poke_enabled` 配置项
- 触发概率由 `poke_probability` 控制（0-100）
- 支持群白名单与黑名单
- 语录库为空时保持静默，避免戳一戳产生无意义回复

## 配置项

在 AstrBot 插件设置页面中修改：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `storage` | 字符串 | `""` | 数据存储根目录，留空使用 AstrBot 默认目录 |
| `global_mode` | 布尔 | `false` | 全局模式：开启后随机语录在所有群/私聊间共享 |
| `delete_permission` | 字符串 | `"管理员"` | 删除权限：群员 / 管理员 / 群主 / Bot管理员 |
| `blacklist` | 列表 | `[]` | 拒绝上传语录的用户 QQ 号列表 |
| `avatar_provider` | 字符串 | `"qlogo"` | 头像来源：`qlogo`（QQ 头像接口）或 `platform`（需 Napcat 权限） |
| `image.width` | 整数 | `1280` | 语录图片宽度（px） |
| `image.height` | 整数 | `427` | 语录图片高度（px） |
| `image.bg_color` | 字符串 | `"#000"` | 语录卡片右侧背景色 |
| `image.text_color` | 字符串 | `"#fff"` | 语录卡片文字颜色 |
| `image.font_family` | 字符串 | 系统默认 | 语录卡片字体 |
| `image_signature_use_group` | 布尔 | `false` | 语录图片签名使用群名片而非 QQ 昵称 |
| `performance.text_mode` | 布尔 | `false` | 纯文字语录直接发送头像与文本，不渲染卡片 |
| `performance.render_cache` | 布尔 | `true` | 上传后预渲染新语录，并在启动后后台补齐旧语录卡片缓存 |
| `performance.render_wait_timeout` | 浮点数 | `0.8` | 冷缓存最多等待秒数，超时先发送纯文本 |
| `poke_enabled` | 布尔 | `false` | 启用戳一戳触发随机语录 |
| `poke_probability` | 整数 | `20` | 戳一戳触发概率（0-100） |
| `poke_group_whitelist` | 列表 | `[]` | 戳一戳触发的群白名单（留空不限制） |
| `poke_group_blacklist` | 列表 | `[]` | 戳一戳触发的群黑名单 |

## 存储结构

插件数据默认保存在 `data/plugin_data/quotes/`：

```
quotes/
├── quotes.sqlite3              # 语录、标签映射、随机图库、资源元数据与已发送指纹索引
└── groups/
    └── {session_key}/          # 群号 或 private_QQ号
        ├── images/             # 图片文件
        ├── media/              # 聊天记录中的语音/视频/文件
        └── cache/              # 后台预渲染缓存
```

- 每个群/私聊会话拥有独立的数据目录
- `global_mode` 仅影响查询范围，不改变物理落盘目录
- 聊天记录语录中的图片仍进入 `images/`，语音/视频/文件进入 `media/`，都按会话独立管理
- SQLite 使用 WAL 模式，并通过事务同步更新语录、资源索引和引用计数
- 标签映射保存在 `quote_bindings` 表，以 `(session_key, qq)` 为主键，并保证 `(session_key, tag)` 唯一
- 图库映射保存在 `gallery_images` 表，通过 `asset_id` 复用 `image_assets` 中的压缩图片
- 普通语录、聊天记录语录和图库共享当前会话的图片资源池；删除引用时只有 `ref_count` 归零才删除实际文件
- 图库近期发送历史保存在 `gallery_sent_records` 表，每个图库最多保留 200 条记录
- 随机语录的上一条选择保存在 `quote_random_state` 表，用于跨重启和并发场景下严格防止连续重复
- 数据库 schema 会在启动时从 v1/v2/v3/v4 原地升级至 v5；升级仅新增所需表和索引，不改写已有语录和资源数据
- 首次启动时自动导入旧版根目录 `quotes.json` 和分会话 JSON 数据
- 根目录旧文件备份为 `quotes.json.bak`；分会话 JSON 备份为 `*.json.migrated.bak`

## 重复图片检测

上传图片时进行双重判重和资源复用：

1. **SHA-256 精确匹配** — 完全相同的图片复用已有 `asset_id`
2. **dhash 感知哈希近似匹配** — 经过压缩、缩放或轻微编辑的同图也复用已有资源
3. **单次上传内部判重** — 同一条语录或聊天记录里重复出现同图时拒绝上传

单次上传内部命中重复时会提示：`语录图片已存在`

若同一会话内、同一归属用户下已存在相同内容的语录，则会提示：`语录内容已存在`

## 依赖

- `httpx >= 0.24` — 异步 HTTP 客户端
- `Pillow >= 10.0` — 图片处理（感知哈希计算）

## 说明

- 基于 NapCat/OneBot v11 平台，调用 `get_msg`、`get_image`、`get_group_member_info` 等接口
- 语录卡片渲染使用 AstrBot 内置浏览器渲染能力
- 头像来源：`https://q1.qlogo.cn/g?b=qq&nk={qq}&s=640`
